# Anotador de Truco

Web app para anotar los puntos del truco. Un solo `index.html`, sin dependencias: se abre en el navegador (celu o compu) y listo.

- Dos equipos con nombre editable (tocá el nombre para cambiarlo).
- Puntos con +1, +2, +3 y −1 para corregir.
- Fósforos en cuadraditos de 5, separados en malas y buenas.
- Partida a 15 o a 30. Debajo de cada número dice cuánto le falta a cada equipo (sirve para la falta envido).
- Deshacer, nueva partida (con doble toque si hay una en curso) y cuenta de partidas ganadas.
- La partida queda guardada en el navegador y la pantalla no se apaga mientras se juega.
